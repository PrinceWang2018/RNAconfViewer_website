RNA Conformation Viewer

Predict, explore and present RNA conformations on your own computer. RCV is a free, open-source desktop application for RNA 3D conformation prediction, interactive molecular visualization, conformational ensemble analysis, and RNA conformational switching studies.

Unlike tools focused only on displaying a single RNA structure, RCV combines 3D visualization with linked secondary-structure views, multi-conformation exploration, switching analysis, mutation scanning, and publication-ready figure generation.

RCV supports Windows, macOS, and Linux. It is designed for researchers in RNA biology, structural biology, computational biology, and bioinformatics.

Keywords: RNA 3D structure viewer, RNA conformation visualization, RNA conformational ensemble, RNA conformational switching, RNA structure analysis, molecular visualization, bioinformatics software.

RNA structure is not confined to a single answer, and neither is life.

  • Linked 2D and 3D. The secondary structure follows the 3D view, with shared colours, hover and selection. Learn more ›
  • Switch analysis. Boltzmann populations of 2D states and a point-mutation scan. Learn more ›

Install

Windows

  1. Download RCV-0.7.3-Windows-x64-Setup.exe.
  2. Run the installer and follow the steps. Optionally create a desktop shortcut and associate .rcv files with RCV.
  3. Start RCV from the Start menu. The Start menu also has RCV with demo ensembles, the RCV User Guide and What is new in RCV.

If Windows SmartScreen shows a warning, choose More info › Run anyway. RCV uses the Microsoft Edge WebView2 runtime, which is part of Windows 11 and current Windows 10.

macOS

  1. Download the .dmg for your Mac (Apple Silicon or Intel).
  2. Open the disk image and drag RCV to the Applications folder.
  3. The first time, right-click RCV and choose Open (or System Settings › Privacy & Security › Open Anyway), because the app is not yet notarised by Apple.

To open an .rcv file on macOS, use File › Open inside RCV. RCV needs macOS 14 (Sonoma) or later.

Linux

  1. Download the .deb (Debian, Ubuntu, Linux Mint) or the .rpm (Fedora, RHEL, Rocky, AlmaLinux, openSUSE).
  2. Install it from the download folder: 
    sudo apt install ./RCV-0.7.3-Linux-amd64.deb                 # Debian, Ubuntu, Linux Mint
sudo dnf install ./RCV-0.7.3-Linux-x86_64.rpm                # Fedora, RHEL, Rocky, AlmaLinux
sudo zypper install --allow-unsigned-rpm ./RCV-0.7.3-Linux-x86_64.rpm   # openSUSE
  3. Start RCV from the applications menu or type rcv in a terminal. Right-click the menu entry for RCV with demo ensembles and the RCV User Guide; .rcv files open with RCV.

RCV opens in a Chrome, Chromium or Edge app window when one of them is installed, otherwise in your default browser, and quits when you close that window. The user guide is also in /opt/rcv/docs.

Installation from source (any system)

Requirements: Python 3.10 or later with numpy and scipy. ViennaRNA is needed for prediction from sequence and for the switch analysis.

git clone https://github.com/PrinceWang2018/RNAconformer.git
cd RNAconformer
pip install -e .                        # installs the rcv and rnafold3d commands
conda install -c bioconda viennarna     # or: pip install ViennaRNA
pip install pywebview                   # optional: native window

Check the installation

rcv --demo        # opens RCV with the HIV-1 TAR NMR ensemble and two predictions
rcv               # opens the start page

Without pywebview, RCV opens in an Edge or Chrome application window. Useful options: --port 8765, --projects-dir DIR, --shell auto|webview|window|browser.

Get started

The start page

When RCV starts, it shows the two ways to use it, side by side:

  1. Predict RNA conformations from sequence(s). Paste one RNA sequence, or several in FASTA format, and click Predict conformations (next section).
  2. View experimental or predicted structures of one RNA. Click Open files… or drop files on the card: PDB/mmCIF files, a multi-model NMR file, an .rcv file or a prediction folder. Several structure files of the same RNA open together as one ensemble. Fetch PDB… downloads an entry from the PDB; Demo ensembles opens examples to look around first (Open your own structures).

Recent predictions, below the two cards, lists the latest runs in your projects folder; click one to reopen it instantly. Browse folders… and All prediction runs… find older ones. You can come back to the start page at any time with the start-page button in the toolbar or Ctrl+H, and the globe button at the top chooses the interface language.

Try it: click Demo ensembles. Three ensembles open in the left panel: the TAR NMR ensemble and the TAR and tRNA predictions. The rest of this tutorial uses them.

Predict from sequence

RCV predicts an ensemble of distinct all-atom 3D conformations from a sequence with its built-in rnafold3d engine. The engine looks for related experimental structures (templates) in its built-in library of 3,964 RNA chains from the PDB and builds 3D models on them; it also builds models for several ViennaRNA secondary-structure hypotheses (the MFE and distinct suboptimal structures), with junction shapes taken from known structures, searches their folds, validates every model and keeps a ranked set of structurally different conformations (How it works). Everything runs on your own CPU cores; no internet connection and no GPU are needed.

One sequence

  1. Paste the sequence into the box on the start page: plain text or FASTA, T is read as U. The line under the box checks the input as you type and estimates the run time. Leave the box empty to run the demo sequence (HIV-1 TAR, 29 nt).
  2. Optional: open Advanced settings to set
    • a name for the run;
    • the number of conformations to keep;
    • the sampling depth: Fast, Standard or Thorough (2, 4 or 8 trajectories per kept conformation; deeper sampling takes longer and explores more);
    • the number of CPU cores;
    • a known secondary structure in dot-bracket notation, if you have one;
    • the random seed. The same seed and version always give the same result;
    • Use related experimental structures (templates), on by default. Switch it off for a physics-only prediction, for example to test whether a design folds on its own.
  3. Click Predict conformations (or press Ctrl+Enter).

The progress view shows each stage (secondary structures → 3D sampling → validation and selection → opening the viewer), a progress bar with the time left, and plain-language notes on what the engine is doing: the templates found, the ViennaRNA hypotheses and their energies, the cores used, trajectories that were rejected and why, and the conformations kept. Cancel stops the engine. When the run finishes, the viewer opens. The run folder holds PDB and mmCIF files, the engine manifest and a <name>.rcv file.

Several sequences (batch)

  1. Paste a multi-record FASTA text, or use Load a FASTA file… (dropping a FASTA file on the box works too). A dot-bracket line after a sequence is used as its known secondary structure.
  2. RCV lists the sequences with a check for each and offers Predict N sequences (up to 100). The sequences run one after another, each on all chosen cores.
  3. The progress view shows one stage per sequence and an overall time estimate. A failed sequence does not stop the batch.
  4. When the batch ends, a table lists every sequence (conformations, best score, MFE ΔG, number of 2D states, time, status). Choose the prediction to open (radio button or double-click, then Open selected in the viewer). The others stay in the batch folder as .rcv files, with batch_summary.csv and batch.json.

The Details tab shows the template of every conformation, with a link to its PDB entry.

Typical run times on an 8-core laptop: a 12–14 nt hairpin with Fast sampling, 10–60 s; a 29 nt hairpin with Standard sampling, 5–7 minutes. With 16 cores and Thorough sampling, the 60–250 nt CASP16 RNAs took 1–7 minutes each (Benchmark).

Open your own structures

RCV is also a viewer and analysis tool for structures from anywhere: NMR ensembles, MD snapshots, or models from any 3D predictor.

  • Formats: PDB, mmCIF, multi-model (NMR) files, rnafold3d prediction folders, .rcv files and RCV workspaces.
  • How to open: Open files… on the start page, File › Open (Ctrl+O), or drop files anywhere on the window.
  • One ensemble from several files. Several structure files, or the models of one multi-model file, open together as one ensemble of the same RNA, in file-name order (model_2 before model_10). The first is the reference for superposition. Residues are matched by position when the sequences are identical, otherwise by author numbering. Files of different RNAs opened together give one ensemble per RNA.
  • Fetch from the PDB (Fetch PDB…, Ctrl+Shift+F, or console fetch 1ANR): type a 4-character PDB ID, optionally a chain. RCV downloads the mmCIF file from the RCSB PDB into projects/fetched/ and opens it. This is the only time RCV uses the internet, and only when you ask.

From a terminal:

rcv models/*.pdb          # several files of one RNA: one ensemble, one conformation per file
rcv models/               # the same from a folder
rcv 1ANR.cif              # multi-model file: one conformation per model
rcv 1ANR.cif --chain B    # one chain of a multi-chain file
rcv a.pdb b.pdb --separate  # every file as its own ensemble

Wildcards such as models\*.pdb also work in the Windows Command Prompt and PowerShell. Multi-chain complexes and non-canonical base-pair annotation are not supported yet.

Try it: press Ctrl+Shift+F, type 1EHZ and compare the crystal structure of tRNAPhe with the demo prediction.

Reference: user guide §11.

AlphaFold 3 in RCV

RCV can show AlphaFold 3 predictions as ensembles, with all its analyses (switching, pathways, probing data, publication output). AlphaFold 3 is not included in RCV.

  • AlphaFold Server results. Download the .zip of a job from the AlphaFold Server and open it with AlphaFold Server results on the start page (card 2). All sampled models open as one ensemble, best ranking score first, with the pLDDT of every nucleotide (colour by Confidence), the ranking score, pTM and the fraction disordered as metrics. The output folder of a local AlphaFold 3 run opens the same way.
  • Your own AlphaFold 3 installation. On the start page (card 1) choose Engine: AlphaFold 3 (local) and fill in AlphaFold 3 settings… once: the Python of the AlphaFold 3 environment, run_alphafold.py, the model parameters and, optionally, the databases. For Docker, WSL or a cluster, give a custom command instead. Check tests the installation. RCV writes the input, runs AlphaFold 3, shows its log and opens every model as one ensemble.

Reference: user guide §2, §3.2.

Step through the conformations

  • ←/→ previous/next, Home/End first/last, Space plays through all conformations.
  • E overlays the whole ensemble; P shows putty (tube width = flexibility across the ensemble).
  • Morphs are smooth interpolations between superposed conformations: a visual aid, not a simulated pathway.

The Energy tab

Choose a metric at the top (energy, scores, descriptors, measurements, confidence…). The large value shows it for the shown conformation, with the change from the previous one. Below are the energy profile, a landscape view (Funnel, the topology-aware Map of section 12, or classical MDS) whose marker follows every morph, the additive energy terms and a two-sided base-pair arc diagram. Every chart has an export button (PDF, SVG, PNG, TIFF, copy, or Open in the plot studio); right-click a table to copy it as tab- or comma-separated text.

The window behaves like a desktop program: text is not selected by accident, right-click shows RCV's own menus, and browser shortcuts are replaced (Ctrl+F selects residues, Ctrl+P exports an image).

Reference: user guide §4.

Linked 2D and 3D

The secondary structure is always in view and always in step with the 3D model.

The 2D window

Press D (or View › 2D structure window) for a small window in a corner of the 3D view. It draws the secondary structure of the shown conformation (ViennaRNA NAView layout, 5′/3′ ends at the bottom):

  • nucleotides are coloured exactly like the 3D structure, in any scheme and with custom colours;
  • hover a nucleotide to highlight it in 3D and in the sequence bar (and the other way round); click selects (Shift adds), double-click centres the 3D view on it;
  • when the conformation changes, the drawing morphs with the 3D model: pairs that break fade out in the first half, new pairs fade in during the second half and stay orange; pseudoknotted pairs are purple arcs;
  • buttons move it to another corner and switch between small, medium and large; maximise it from its title bar.

The sequence bar

The sequence, numbered and coloured like the structure, with the dot-bracket of the shown conformation underneath. Positions whose pairing changed since the previous conformation are underlined. Click, Shift+click or drag to select; hover to highlight in 3D and 2D.

The same 2D drawing appears in transition videos, figure panels and the interactive HTML page.

Try it: open the TAR prediction, press D, then step with →. Watch which pairs turn orange and which positions are underlined in the sequence bar.

Reference: user guide §5.

Pull to switch

Ask the structure directly: what happens if this part moves over there?

  1. Choose the Pull tool (G), or hold Alt.
  2. Drag a residue. The structure stretches elastically, and the computed conformation that best matches the pull is shown as an orange ghost with its energy change.
  3. Release: the structure morphs to that conformation. Among about equally good matches RCV takes the most stable one (relatively stable, not necessarily the lowest).
  4. If no existing conformation fits, click Explore new conformations. RCV runs the engine with your pull as a temporary bias, relaxes the new models without it, and adds the stable ones to the ensemble. This takes a few minutes; you can keep working.

In tests on TAR, the chosen conformation put the dragged residue 2.3–3.2 Å from the cursor, against about 6 Å for staying put. Pull switching chooses among computed conformations; helices are rigid.

Reference: user guide §6.

Mouse tools, annotations and undo

The left mouse button works like in a drawing program. Choose the tool in the toolbar or with one key:

ToolKeyLeft button in the 3D view

Annotations are residue labels, region labels (a bracket over a selection, for example "anticodon stem") and free notes or titles (Edit › Add a title / note). They follow the structure during morphs, appear in images, figure panels and videos, and are saved in .rcv files.

Undo / redo (Ctrl+Z, Ctrl+Y) step through every edit of the open ensemble: annotations, paint and custom colours, labels, hidden residues, representations, measurements, selection, colour scheme, style, background, surface and transparency, including changes made with console commands. Each ensemble has its own history. Clear (eraser button, Edit menu) removes one kind of edit at a time, or everything; clearing can be undone too.

Measurements, named selections and scenes

  • Measurements. With the Measure tool (M), click two atoms for a distance; the console adds angles and dihedrals. Measurements are dashed lines with live values that follow every morph. Each measurement also becomes a metric, so you can plot its value across all conformations in the Energy tab and export it in the CSV table.
  • Named selections (console select name, … or + Selection in the Details tab) are chips you can click to reselect, zoom to or delete. Any command accepts them by name.
  • Scenes (view save name or + Scene) remember the camera, conformation, colours, representation, overlay, putty and selection. Recalling a scene flies the camera there and morphs to its conformation, which makes it easy to return to the same figure view.
distance d1, 22/N1, 27/N3        # a distance between two atoms (residue/atom)
angle a1, 22/P, 23/P, 24/P
select bulge, resi 23-25
view save closeup                # later: view closeup
metric measure.d1                # plot d1 across the ensemble

All of these, plus custom colours, labels and hidden residues, are saved in .rcv files.

Reference: user guide §10.

Representations, colours, palettes and surface

  • Representations (1–5): Cartoon, Cartoon + atoms, Sticks, Ball & stick, Spheres, for the whole RNA or, from the console, for part of it (show sticks, switching).
  • Colour schemes (toolbar or C): Nucleotide, Helices, Structure elements (stem, hairpin loop, internal loop, bulge, multibranch loop, pseudoknot, exterior), Base pairing, Pairing frequency, Switching residues, Flexibility (RMSF), Displacement from previous, Position, Uniform, and, after the analyses, Mutation sensitivity, Kinetic sensitivity, Mechanism, Reactivity and Confidence. Every scheme has a legend; custom colours go on top.
  • Styles and backgrounds: Studio, Illustrative, Glossy, Depth cue, Plain; white, paper, grey, slate, dark, black or custom.
  • Palettes (Color › Palettes and custom colours…): RCV, Okabe–Ito and Tol bright / muted (colour-blind safe), Pastel, Grayscale for print, or your own. Analyse

Switch analysis

For an RNA switch the questions are usually: which state dominates, and what would change that? The Switch tab answers them at the secondary-structure level with ViennaRNA (Turner 2004 energies).

  1. Read the 2D states. The table lists the distinct secondary structures of the ensemble's conformations, each with its free energy, its probability in the full ViennaRNA ensemble, its share of the population among these states (Boltzmann) and the number of models (click to step through them). The MFE and the ensemble free energy are shown for reference.
  2. Change the temperature (0–95 °C) to look at thermo-switches, or open Conditions for salt and ligands (section 13).
  3. Choose states A and B. RCV evaluates every point mutation (3 × length mutants) and draws a heat map of how each shifts the balance (ΔΔG): blue favours A, orange favours B, saturating at ±4 kcal/mol. Hover a cell for the shift of the A/B equilibrium. The tables list the strongest mutations in each direction with the probabilities of A and B in the mutant.
  4. Act on it. Click a cell to select the residue in 3D, copy the mutant as FASTA, or Predict in 3D (opens the start page with the mutant ready). Colour 3D by mutation sensitivity paints each residue by its largest |ΔΔG|; Copy scan as table gives all mutations as tab-separated text.

With a ligand set in Conditions, the ligand response chart shows the share of every state from 1 nM to 1 mM and the half-way concentration of the states that bind.

These are secondary-structure estimates; the 3D model scores are not used, and populations are not experimental values. A mutation that turns a pair non-canonical removes that pair from the state.

Reference: user guide §7.

Pathway A → B

The Pathway tab shows how one conformation turns into another. To start, choose A and B in the tab (or previous → shown, or Shift+click a point on the ensemble map to make it B). It is also in Tools › Pathway A → B and the console (pathway conf_001, conf_005). RCV answers three questions.

1. Is the switch feasible, and along which route?

  • A and B first relax into their basins, the local energy minima they reach by steepest descent. A structure that is not itself a minimum (a frayed NMR model, a strained pair) slides into its basin first, so barriers are measured between basins. If A and B reach the same basin, no barrier separates them: they are fluctuations of one fold, and the verdict says so.
  • Otherwise RCV computes the direct refolding path (only pairs of A open, only pairs of B form) and routes through intermediates: the basins of the other 2D states of the ensemble and local minima from Boltzmann samples (fixed seed, so the result is reproducible).
  • The basins and the saddles between them form a network with Arrhenius rates k = k₀·exp(−(saddle − E)/RT) (k₀ adjustable, default 10⁶ s⁻¹). Transition path theory ranks the routes by reactive flux, and the time to switch is the mean first-passage time from A to B.

Reading the verdict card: the effective barrier, the barriers of the direct path and of the best single route, ΔG(A→B), the half-life of A, and a plain-language feasibility statement. For example, a half-life over a year means the switch is not feasible by refolding alone; it needs unfolding, a helper such as a helicase or chaperone, or happens during transcription. A trap note appears when a deeper well holds the RNA for most of the switching time.

Reading the charts: the map shows the routes through 3D conformations (2D-only intermediates are listed, not drawn). The energy profile shows every base-pair move: relaxation into the basins (dotted), the route (solid), the direct path (dashed) and the saddle. Hover a step to see which pairs open or form, highlighted in 3D.

2. What limits it?

  • The cooperative unit: the base pairs that must open together on the climb to the highest saddle. The nucleus: the B pairs that form right after it.
  • Rigid modules: RCV splits the molecule into groups that move as one body between A and B (seeded by the shared helices, fit within 2 Å). Each module is reported with its turn (degrees), shift (Å) and screw axis relative to the largest module M1, and the time window of its base-pair events (0 = A, 1 = B). Hinges are the flexible residues with the largest backbone change. The module that carries the cooperative unit is the rate-limiting coordinated motion.
  • Colour by mechanism, by event order or by module paints the 3D view. Play the mechanism morphs A into B with the modules turning in the order of their events (chain kept connected); Rigid-module morph moves all modules together; Mechanism video… records it.

3. Which mutations change the rate?

The φ-value scan (button in the tab, or console phiscan) evaluates every point mutation along the route:

  • ΔΔG‡, the change of the barrier: blue = faster switching, orange = slower;
  • ΔΔG, the change of the A/B balance;
  • φ = ΔΔG‡/ΔΔG (where |ΔΔG| ≥ 0.6 kcal/mol): near 1 where the nucleotide already looks as in B at the saddle, near 0 where it still looks as in A.

The lists name the mutations that speed the switch up or slow it down most, with the factor on the rate. Colour 3D by kinetic sensitivity and Copy scan as table work as in the Switch tab.

pathway conf_001, conf_005       # console
phiscan
mechanism staged                 # or: mechanism rigid
rcv pathway tRNA.rcv --a conf_001 --b conf_005 --scan -o result.json   # command line
Try it: open the TAR prediction (its conformations come from two different secondary structures), open the Pathway tab, choose one conformation of each as A and B, read the verdict and click Play the mechanism.

The kinetics are computed for nested canonical pairs at the secondary-structure level (ViennaRNA, under the current conditions). Barriers are upper bounds; rates are order-of-magnitude estimates that scale with k₀. Rigid modules are only as reliable as the two 3D models, and the morph illustrates the analysed mechanism; it is not a simulated trajectory.

Reference: user guide §8.1.

Topology-aware ensemble map

The Map view (Energy tab, also in the Pathway tab, the plot studio and the HTML page) shows the whole ensemble at a glance:

  • Every secondary-structure topology, the abstract shape of the 2D structure ([] one hairpin, [][] two hairpins, [[][]] a multibranch helix), has its own disk, labelled T1, T2, … with a small drawing of its 2D structure. No other topology enters it.
  • Disks are arranged by 3D similarity and linked when their topologies differ by one helix. Inside a disk, conformations are placed by C4′ RMSD, and conformations with the same 2D state stay together.
  • Click a point to morph to it; Shift+click makes it B in the Pathway tab, whose routes are drawn on the map.
  • The caption reports how faithful the map is (trustworthiness, topology purity, stress), compared with classical MDS, which is still available as MDS.

In the plot studio, the map can be coloured by any metric and exported with the A → B routes.

Conditions and ligands

The balance between conformations depends on the environment. Open Tools › Conditions…, or the conditions link in the Switch and Pathway tabs, and set:

  • Temperature in °C;
  • Na⁺ concentration in mM (ViennaRNA salt correction; 1021 mM is the standard state of the Turner parameters);
  • a ligand that binds an aptamer forming a hairpin or interior loop: the preset theophylline aptamer (Kd 0.32 µM), or your own motif and Kd, and its concentration in µM. Every structure that forms the motif is stabilised by −RT ln(1 + c/Kd) (two-state binding, ligand in excess). If the motif does not occur in the sequence, RCV tells you.
  • optionally, probing data as pseudo-energies (next section).

Standard conditions resets everything. Conditions are kept per ensemble, saved in .rcv files and used by both the Switch and Pathway tabs, so you can compare, for example, the switching time with and without ligand.

Probing data (SHAPE, DMS)

Chemical probing tells you which nucleotides are unpaired in solution. RCV uses it to check and reweight the ensemble.

  1. Tools › Load probing data (SHAPE / DMS)… and choose a file: position and value (RNAstructure .shape and most lab formats), ShapeMapper .map, CSV with a reactivity column, or one value per line. −999 and NaN mean no data. 
    1	0.12
2	0.85
3	-999
  2. Keep Normalise (2–8 % rule) on unless your data are already normalised. For DMS, only A and C are used.
  3. Read the results:
    • the colour scheme Reactivity paints the structure, and the Details tab shows the profile under the pairing of the shown conformation;
    • the metric SHAPE agreement (AUC) scores each conformation: how well reactivity predicts its unpaired nucleotides (1 = perfect, 0.5 = random);
    • the metric SHAPE data weight is each conformation's weight after a maximum-entropy reweighting of the ensemble to fit the data. θ sets how far the data may move the weights (smaller = more). χ² before and after and the effective number of conformations are reported. Weights near the prior mean the data do not distinguish the conformations.
  4. Optionally, use the reactivities as pseudo-energies for the 2D-state populations in the Conditions dialog (Deigan et al. 2009). These are data-informed estimates, not free energies.

The profile, the fit and the weights are saved in .rcv files. Console: probing file.shape, SHAPE · probing clear. Command line: rcv probing x.rcv --data file.shape [--dms].

The model treats unpaired nucleotides as reactive and paired ones as protected; it does not model flexibility within loops or protection by tertiary contacts or proteins.

Reference: user guide §8.4.

Per-nucleotide confidence

When an ensemble opens, RCV estimates how accurate each nucleotide of every conformation is likely to be: its predicted lDDT against the true structure (0–1, higher is better). This works for any model, predicted by RCV or by another tool.

  • The metric Confidence (predicted lDDT), the mean over the nucleotides, appears in the Energy tab, the conformation list, the plot studio and the HTML page.
  • The colour scheme Confidence (per nucleotide) shows four bands: high (≥ 0.8), medium, low and very low (< 0.5). Use it to see which parts of a model to trust, for example a well-defined stem next to an uncertain loop.

The model is a small neural network (two dense layers, about 3,200 parameters) that runs on your CPU in a fraction of a second, with no GPU and nothing to download. It reads only the coordinates (pairing, stacking, backbone and sugar geometry, packing, clashes, chain breaks) and never changes a structure. Turn it off in View › Preferences. Command line: rcv confidence x.rcv -o confidence.json.

Cross-validated per-nucleotide correlation r = 0.82; on benchmark RNAs never seen in training, r = 0.75–0.84. Picking the top model by confidence is not reliably better than the engine's own ranking, so the ranking is kept and confidence is shown as an additional guide.

Reference: user guide §8.5.

The .rcv file

Save with Ctrl+S (File › Save as .rcv). One .rcv file holds everything about one RNA: all conformations, energies, 2D structures and layouts, validation reports, provenance (engine version, parameters, seeds, source-file checksums), conditions, probing data, and your view: camera, colours, selections, labels, measurements, annotations, scenes and the command log.

  • It is typically 10–14× smaller than PDB (the 20-model TAR NMR ensemble: 77 kB instead of 1.0 MB) and opens instantly, without re-evaluation.
  • It is an open format: a ZIP archive (rename it to .zip to look inside) with a JSON manifest, compressed coordinates at 0.001 Å precision, the session, a thumbnail, the methods text and a README. Damaged files are detected by a checksum.
  • The installers can register .rcv files, so they open with a double-click.
  • To keep several RNAs together, save a workspace (Ctrl+Shift+S): every open ensemble in one JSON file.

rcv extract my_rna.rcv -o pdb/           # back to PDB files (--multi: one multi-model PDB)

Writing an interface plugin (JavaScript)

An interface plugin is an ES module whose default export has an activate(api) function. The API gives read-only access to the current ensemble and selection, events (ensemble, conformation, morph, selection, …), panels, menu items, overlays, colour schemes and metrics.

// my-plugin.js
export default {
  id: 'my-plugin',
  name: 'My plugin',
  version: '1.0',
  description: 'Short description shown in the Plugins menu.',
  activate(api) {
    api.metrics.register({
      key: 'n_residues', label: 'Residues', unit: '', lower_is_better: null,
      description: 'Number of residues (example).',
      compute: (ens, k) => ens.residues.length,
    });
  },
};

Writing an analysis plugin (Python)

An analysis plugin defines a PLUGIN dictionary and a compute(sequence, residues) function that returns one value per metric. residues is a list (5′ to 3′) of {atom_name: xyz} dictionaries after superposition.

# end_distance.py
import numpy as np

PLUGIN = {
    'id': 'end_distance',
    'name': 'End distance',
    'metrics': [{'key': 'end_to_end', 'label': "5'-3' distance", 'unit': 'Å',
                 'lower_is_better': None, 'description': "C4'-C4' distance of the chain ends."}],
}

def compute(sequence, residues):
    a, b = residues[0].get("C4'"), residues[-1].get("C4'")
    if a is None or b is None:
        return {'end_to_end': None}
    return {'end_to_end': round(float(np.linalg.norm(a - b)), 2)}

The plugin API is version 3 (RCV 0.6 added console commands, annotations, the active palette, surface and transparency control and chart export; 0.6.1 added per-ensemble metrics and plugin state saved in .rcv files); plugins written for versions 1 and 2 keep working. The complete plugin developer guide explains everything; the built-in plugins in src/rcv/static/plugins are complete examples.

About

RCV (RNA Conformation Viewer) predicts, explores and presents the conformations of an RNA. Many RNAs do not have a single structure but switch between several; RCV is built to look at these ensembles as a whole rather than at one model at a time.

How it works

The rnafold3d engine combines physics with known structures and does not use deep learning:

sequence ─► template search in 3,964 PDB RNA chains (built in, 21.5 MB)
         ─► secondary-structure hypotheses: template base pairs + ViennaRNA MFE and suboptimals
         ─► rigid all-atom A-form stems (calibrated geometry)
         ─► fold-tree search in torsion space (template and junction-shape restraints)
         ─► loop closure in the template's shape, clash relief
         ─► all-atom refinement onto the template
         ─► independent all-atom validation
         ─► ranked, structurally distinct ensemble

Predictions run on your CPU cores and the 3D view is rendered on your GPU. No data leave your computer. Runs are deterministic for a given seed and version.

Limitations

  • Without a related experimental structure, accuracy is good for hairpins and small motifs (about 2–4 Å) but limited for large multi-branched RNAs.
  • Switch and pathway analyses are at the secondary-structure level (ViennaRNA); 3D energies are model scores, not free energies, and the mechanism morph illustrates the analysed mechanism rather than simulating a trajectory.
  • Non-canonical base-pair annotation and multi-chain complexes are not yet supported.
