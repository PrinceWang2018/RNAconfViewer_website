RNA Conformation Viewer

RCV is a free desktop application for predicting, exploring and presenting the conformations of an RNA. It combines the rnafold3d prediction engine with an interactive 3D/2D viewer, and runs entirely on your own computer.

RNA structure is not confined to a single answer, and neither is life.

Download RCV 0.7.1  Get started

Main features

  • Pathways: how A turns into B. New The refolding barrier and routes between two conformations, the time to switch and any traps, the base pairs and coordinated 3D motions that limit the switch, and the point mutations that speed it up or slow it down (φ-value scan). A mechanism morph plays the motion.
  • Topology-aware ensemble map. New Every secondary-structure topology has its own region; inside it, conformations are placed by 3D similarity, with the switching routes drawn on top.
  • Probing data. New Load SHAPE or DMS reactivities: see how well each conformation agrees and reweight the ensemble to fit the data.
  • Conditions and ligands. New Temperature, Na+ and a ligand binding to an aptamer change the balance between conformations and the switching path.
  • Per-nucleotide confidence. New An optional small neural network estimates how accurate each part of a model is. It runs on any laptop; no GPU needed.
  • Prediction from sequence. Paste a sequence or a multi-sequence FASTA file; RCV returns a ranked, validated all-atom ensemble.
  • Open your own structures. NMR ensembles, MD snapshots, PDB/mmCIF files from any predictor. Several files of one RNA, or one multi-model file, open together as one ensemble.
  • Pull to switch. Drag a residue and the structure moves to the nearest stable computed conformation.
  • Linked 2D and 3D. The secondary structure follows the 3D view, with shared colours, hover and selection.
  • Switch analysis. Boltzmann populations of 2D states and a point-mutation scan.
  • Command console. A selection language for RNA ensembles and familiar molecular-viewer commands.
  • Publication output. Figures, figure panels, a plot studio (clustered RMSD matrix, RMSF, energy funnel), annotations, colour-blind-safe palettes, molecular surfaces, transition videos, interactive HTML pages and methods text.
  • Your language, your layout. English, 简体中文, 繁體中文, 日本語, 한국어, Español, Français, Deutsch, Italiano, Português and Русский; every panel can be shown, hidden or maximised.
  • One file per RNA. The open .rcv format stores all conformations, 10–14× smaller than PDB.

Install

Windows

  1. Download RCV-0.7.1-Windows-x64-Setup.exe.
  2. Run the installer and follow the steps. Optionally create a desktop shortcut and associate .rcv files with RCV.
  3. Start RCV from the Start menu. The Start menu also has RCV with demo ensembles, the RCV User Guide and What is new in RCV.

If Windows SmartScreen shows a warning, choose More info › Run anyway. RCV uses the Microsoft Edge WebView2 runtime, which is part of Windows 11 and current Windows 10.

macOS

  1. Download the .dmg for your Mac (Apple Silicon or Intel).
  2. Open the disk image and drag RCV to the Applications folder.
  3. The first time, right-click RCV and choose Open (or System Settings › Privacy & Security › Open Anyway), because the app is not yet notarised by Apple.

To open an .rcv file on macOS, use File › Open inside RCV. RCV needs macOS 14 (Sonoma) or later.

Linux

  1. Download the .deb (Debian, Ubuntu, Linux Mint) or the .rpm (Fedora, RHEL, Rocky, AlmaLinux, openSUSE).
  2. Install it from the download folder: 
    sudo apt install ./RCV-0.7.1-Linux-amd64.deb                 # Debian, Ubuntu, Linux Mint
sudo dnf install ./RCV-0.7.1-Linux-x86_64.rpm                # Fedora, RHEL, Rocky, AlmaLinux
sudo zypper install --allow-unsigned-rpm ./RCV-0.7.1-Linux-x86_64.rpm   # openSUSE
  3. Start RCV from the applications menu or type rcv in a terminal. Right-click the menu entry for RCV with demo ensembles and the RCV User Guide; .rcv files open with RCV.

RCV opens in a Chrome, Chromium or Edge app window when one of them is installed, otherwise in your default browser, and quits when you close that window. The user guide is also in /opt/rcv/docs.

Installation from source (any system)

Requirements: Python 3.10 or later with numpy and scipy. ViennaRNA is needed for prediction from sequence and for the switch analysis.

git clone https://github.com/PrinceWang2018/RNAconformer.git
cd RNAconformer
pip install -e .                        # installs the rcv and rnafold3d commands
conda install -c bioconda viennarna     # or: pip install ViennaRNA
pip install pywebview                   # optional: native window

Check the installation

rcv --demo        # opens RCV with the HIV-1 TAR NMR ensemble and two predictions
rcv               # opens the start page

Without pywebview, RCV opens in an Edge or Chrome application window. Useful options: --port 8765, --projects-dir DIR, --shell auto|webview|window|browser.

Tutorial

This tutorial covers the main tasks in RCV. It takes about 20 minutes, most of which is waiting for a prediction. For every menu, option and command, see the full user guide.

Contents: Start page · Predict · The window · Pull to switch · Switch analysis · Pathway A → B · Console · Export · Shortcuts

The start page

When RCV starts, it shows the two ways to use it, side by side:

  1. Predict RNA conformations from sequence(s). Paste one RNA sequence, or several in FASTA format, and click Predict conformations (next step).
  2. View experimental or predicted structures of one RNA. Click Open files… or drop files on the card: PDB/mmCIF files, a multi-model NMR file, an .rcv file or a prediction folder. Several structure files of the same RNA open together as one ensemble. Fetch PDB… downloads an entry from the PDB; Demo ensembles opens examples to look around first.

Recent predictions are listed below the two cards.

Predict from a sequence

  1. Paste an RNA sequence (plain text or FASTA; T is read as U). Leave the box empty to run the demo sequence (HIV-1 TAR, 29 nt).
  2. Choose the number of conformations, the sampling depth (Fast, Standard or Thorough) and the CPU cores. RCV shows an estimated run time.
  3. Optional, under Advanced: a known secondary structure in dot-bracket notation and the random seed.
  4. Click Predict. The progress view shows each stage, the time left and notes on what the engine is doing.

A multi-record FASTA file starts a batch (up to 100 sequences). When the batch ends, choose which result to open; the others are saved as .rcv files with a summary table.

Typical run times on an 8-core laptop: a 12–14 nt hairpin with Fast sampling, 10–60 s; a 29 nt hairpin with Standard sampling, 5–7 minutes.

Explore the ensemble

The conformations are listed on the left, ordered by energy. Hover a conformation to preview it; click it to morph the structure. The timeline below the 3D view plays through all conformations. The right panel shows the energy profile, terms and the ensemble map (Energy), the switch analysis (Switch), the transition between two conformations (Pathway) and full details (Details).

  • Mouse: drag to rotate, right-drag to pan, wheel to zoom, double-click to centre, right-click a residue for its menu.
  • The sequence bar shows the sequence and dot-bracket of the current conformation; changed pairs are underlined.
  • The 2D window (D) draws the secondary structure in the same colours as the 3D model and morphs with it.

Pull to switch

Press G (or hold Alt) and drag a residue. The structure stretches, and the computed conformation that best matches the pull is shown as an orange preview with its energy change. Release to morph to it. Explore new conformations runs the engine with the pull as a temporary bias and adds the new stable conformations to the ensemble.

Switch analysis

The Switch tab lists the distinct secondary structures in the ensemble with their free energy and Boltzmann population at a chosen temperature (0–95 °C).

Choose two states, A and B, to scan all point mutations. The heat map shows how each mutation shifts the balance: blue favours A, orange favours B. Click a cell to select the residue, copy the mutant sequence, or Predict in 3D.

This analysis uses ViennaRNA at the secondary-structure level. Populations are estimates, not experimental values.

Pathway A → B

The Pathway tab shows how one conformation turns into another. Choose A and B (or Shift+click a point on the ensemble map). RCV answers three questions:

  • Is the switch feasible, and along which route? The effective barrier, the half-life of A and a plain-language verdict, with the routes through intermediate structures on the ensemble map and the energy along the refolding path.
  • What limits it? The base pairs that must open together before the saddle (the cooperative unit), the rigid 3D modules and hinges, and the rate-limiting coordinated motion. Play the mechanism morphs A into B in that order.
  • Which mutations change the rate? The φ-value scan of every point mutation lists those that speed the switch up or slow it down.

Tools › Conditions sets the temperature, Na+ and a ligand, and Tools › Load probing data fits the ensemble to SHAPE or DMS reactivities; both are used by the Switch and Pathway tabs.

Like the switch analysis, the kinetics are computed at the secondary-structure level (ViennaRNA). The 3D morph illustrates the analysed mechanism; it is not a simulated trajectory.

Command console

Open the console with `. Type one command per line; Tab completes and help lists all commands. Some examples:

select loop, resi 23-27 and unpaired
color orange, loop
show sticks, switching
distance d1, 22/N1, 27/N3
orient helix H2
png 3000, 2000, 600

Commands can be saved in a script file (.rcvs) and run with run script.rcvs. Every command is stored in the .rcv file as a reproducible record.

Command line

RCV also works without the window:

rcv models/*.pdb                        # several structure files of one RNA: one ensemble
rcv batch my_rnas.fasta                 # predict every sequence, one .rcv each
rcv convert models/*.pdb -o my_rna.rcv  # structures to one .rcv file
rcv pathway my_rna.rcv --a 1 --b 5      # how conformation 1 turns into 5
rcv info my_rna.rcv --methods           # contents and methods paragraph
rcv extract my_rna.rcv -o pdb/          # back to PDB files
rcv html my_rna.rcv -o my_rna.html      # interactive web page

Writing an interface plugin (JavaScript)

An interface plugin is an ES module whose default export has an activate(api) function. The API gives read-only access to the current ensemble and selection, events (ensemble, conformation, morph, selection, …), panels, menu items, overlays, colour schemes and metrics.

// my-plugin.js
export default {
  id: 'my-plugin',
  name: 'My plugin',
  version: '1.0',
  description: 'Short description shown in the Plugins menu.',
  activate(api) {
    api.metrics.register({
      key: 'n_residues', label: 'Residues', unit: '', lower_is_better: null,
      description: 'Number of residues (example).',
      compute: (ens, k) => ens.residues.length,
    });
  },
};

Writing an analysis plugin (Python)

An analysis plugin defines a PLUGIN dictionary and a compute(sequence, residues) function that returns one value per metric. residues is a list (5′ to 3′) of {atom_name: xyz} dictionaries after superposition.

# end_distance.py
import numpy as np

PLUGIN = {
    'id': 'end_distance',
    'name': 'End distance',
    'metrics': [{'key': 'end_to_end', 'label': "5'-3' distance", 'unit': 'Å',
                 'lower_is_better': None, 'description': "C4'-C4' distance of the chain ends."}],
}

def compute(sequence, residues):
    a, b = residues[0].get("C4'"), residues[-1].get("C4'")
    if a is None or b is None:
        return {'end_to_end': None}
    return {'end_to_end': round(float(np.linalg.norm(a - b)), 2)}

The plugin API is version 3 (RCV 0.6 added console commands, annotations, the active palette, surface and transparency control and chart export; 0.6.1 added per-ensemble metrics and plugin state saved in .rcv files); plugins written for versions 1 and 2 keep working. The complete plugin developer guide explains everything; the built-in plugins in src/rcv/static/plugins are complete examples.

Release Notes

RCV 0.7.1 — 27 October 2026

The first public release of the 0.7 series. It includes 0.6.1 and 0.7.0, which were not released separately, and adds the analysis of how an RNA switches between its conformations.

New

  • Pathway tab: how A turns into B. A and B relax into their basins of the 2D energy landscape; RCV finds the direct refolding path and routes through intermediates, ranks them by transition-path-theory flux, and reports the time to switch (mean first-passage time), the half-life of A, traps and a plain-language verdict.
  • Bottleneck and coordinated motions: the cooperative unit of base pairs that open before the saddle, the nucleus of B, rigid 3D modules with their turn, shift and hinges, and the rate-limiting coordinated motion. A mechanism morph (and video) plays A turning into B in that order.
  • φ-value scan of all point mutations along the route: the mutations that speed the switch up or slow it down, with colour by kinetic sensitivity.
  • Topology-aware ensemble map: one region per secondary-structure topology, conformations placed by RMSD inside it, routes drawn on top (Energy and Pathway tabs, plot studio, HTML page).
  • Conditions: temperature, Na+ and a ligand binding to an aptamer (theophylline preset, or your own motif and Kd), saved per ensemble.
  • Probing data: SHAPE and DMS reactivities, agreement of every conformation (AUC) and maximum-entropy reweighting of the ensemble.
  • Optional confidence model: the predicted accuracy (lDDT) of every nucleotide as a metric and a colour scheme, from a small neural network that needs no GPU.
  • Command line rcv pathway, rcv probing, rcv confidence; methods text and references for the new analyses; plugin API version 3.

Changed and fixed

  • Start page with the two ways to use RCV: predict conformations from sequence(s), or view experimental or predicted structures of one RNA.
  • Several structure files open as one ensemble, also from the command line (rcv models/*.pdb; wildcards also work in the Windows Command Prompt and PowerShell). Files of different RNAs given together open as one ensemble per RNA.
  • Structure files are read in file-name order (model_2 before model_10).
  • Tracked distances are saved in .rcv files and can be undone; removing one removes its metric.

About

RCV (RNA Conformation Viewer) predicts, explores and presents the conformations of an RNA. Many RNAs do not have a single structure but switch between several; RCV is built to look at these ensembles as a whole rather than at one model at a time.

How it works

The rnafold3d engine is physics-inspired and does not use deep learning:

sequence ─► ViennaRNA secondary-structure hypotheses (MFE + distinct suboptimals)
         ─► rigid all-atom A-form stems (calibrated geometry)
         ─► fold-tree search in torsion space (simulated annealing)
         ─► loop closure and clash relief
         ─► independent all-atom validation
         ─► ranked, structurally distinct ensemble

Predictions run on your CPU cores and the 3D view is rendered on your GPU. No data leave your computer. Runs are deterministic for a given seed and version.

Limitations

  • Accuracy is good for hairpins and small motifs (about 2–4 Å) but limited for large multi-branched RNAs.
  • Switch and pathway analyses are at the secondary-structure level (ViennaRNA); 3D energies are model scores, not free energies, and the mechanism morph illustrates the analysed mechanism rather than simulating a trajectory.
  • Non-canonical base-pair annotation and multi-chain complexes are not yet supported.
