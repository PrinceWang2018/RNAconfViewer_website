Writing plugins for RCV

RCV (RNA Conformation Viewer) can be extended without changing its source code. There are two kinds of plugins:

KindFileRunsGood for
Interface pluginname.js (JavaScript module)in the RCV windowpanels, charts, colour schemes, console commands, menu items, 3D overlays, annotations, metrics computed from the shown data
Analysis pluginname.py (Python)in the local RCV engine, when an ensemble is openedmetrics that need numpy/scipy or heavier computation per conformation

Plugin API version: 2 (RCV 0.6). Everything from version 1 (RCV 0.4–0.5) still works.

1. Quick start

  1. Plugins ▸ New plugin from template… writes a commented template (JavaScript or Python) into your plugin folder and shows where it is. The JavaScript template already adds a metric, a console command, a side panel and a menu item.
  2. Plugins ▸ Open plugin folder opens the folder in Explorer / Finder.
  3. Edit the file in any text editor.
  4. Plugins ▸ Reload window (JavaScript) or restart RCV (Python). Plugins ▸ Manage plugins lists every plugin with its status and any error, and lets you switch plugins on and off.

Plugin folders (created on first use):

SystemFolder
Windows%APPDATA%\RCV\plugins
macOS~/Library/Application Support/RCV/plugins
Linux~/.local/share/rcv/plugins

Plugins in the folders of earlier versions (RNAconfSwitch, ~/.rnafold3d/plugins) are loaded too.

Developer mode (View ▸ Preferences): F12 / Ctrl+Shift+I open the browser developer tools of the RCV window (JavaScript console, debugger, network log), and Shift+right-click shows the browser's own menu. Leave it off for normal use.

2. Interface plugins (JavaScript)

A plugin is an ES module whose default export is an object with id, name, version, description and activate(api):

export default {
  id: 'hello',                 // lower-case and unique
  name: 'Hello',
  version: '1.0',
  description: 'Says hello when the conformation changes.',
  activate(api) {
    api.on('conformation', ({ from, to }) => api.ui.toast(`switched to ${api.ensemble.shortId(to)}`));
  },
};

activate runs once when RCV starts (it may be async). Keep it fast; do heavy work lazily (when a panel opens or a command runs). Check the API version if you rely on version-2 features: if (api.version < 2) return;.

2.6 Colour schemes

api.colors.registerScheme({
  id: 'purines', label: 'Purine / pyrimidine',
  residueColors: (ens, ctx) => ens.residues.map(r => ('AG'.includes(r.name) ? api.palette.colors[0] : api.palette.colors[1])),
  legend: () => ({ title: 'Base type', items: [{ color: api.palette.colors[0], label: 'Purine' }, { color: api.palette.colors[1], label: 'Pyrimidine' }] }),
});

residueColors returns one #rrggbb per residue; ctx.conf is the conformation being coloured (schemes may differ per conformation). A legend is a list of items or a ramp { title, ramp: [colours], min, max }. Use api.palette.colors (the active palette, chosen in Color ▸ Palettes) so your scheme follows the user's palette.

2.7 Metrics

api.metrics.register({
  key: 'loop_size', label: 'Apical loop size', unit: 'nt', lower_is_better: null,
  description: 'Unpaired nucleotides between the last pair and the next pair.',
  compute: (ens, k) => { /* return a number or null for conformation k */ },
});

Metrics appear in the energy panel (profile, funnel, map), the Details table, the plot studio and the CSV export. The key is stored as plugin.<plugin id>.<key>.

2.8 Console commands

api.commands.register({
  name: 'loopsize', args: '[conformation]', help: 'Apical loop size of a conformation',
  run: (args, raw) => `loop size: ${/* ... */ 4} nt`,       // string, array of strings, or nothing; may be async
});

Commands are listed by help, take comma-separated arguments, can be used in scripts (run file.rcvs) and are recorded in the ensemble's command log (saved in .rcv files) like built-in commands. api.commands.run(line) runs any command, which gives plugins the whole console vocabulary (selection language included).

3. The ensemble object

api.ensemble (read-only for plugins):

MemberContent
name, sequenceensemble name, sequence (A/C/G/U)
n, nRes, nAtomsconformations, residues, atoms
residues[r]{ name, comp, num, chain, first_atom, n_atoms } (num = author numbering, may include an insertion code)
atomNames[a], elements[a], atomRes[a]atom name, element, residue index
atomIndex[r][name]atom index of a named atom in residue r
trace[r], c1[r], glyco[r], phos[r]atom index of C4′, C1′, N1/N9, P (−1 if absent)
coords[k]Float32Array of conformation k (superposed; x,y,z per atom)
conformations[k]{ id, label, rank, pairs: [[i, j, type, pseudoknot]], stacks, dbn, input_dbn, values: { metric: number }, validation, cluster, explored }
metrics, metricByKey[key]metric descriptions { key, label, unit, group, lower_is_better, description }
rmsd[a][b], rmsf[r], embedding[k]pairwise C4′ RMSD (Å), per-residue RMSF (Å), 2D similarity map
value(k, key)metric value or null
shortId(k), resLabel(r)display names, e.g. conf_003, G34
partner(k)Int32Array pairing partner per residue (−1 unpaired)
pairInfo(k, r){ partner, type, pk } or null
residueCenter(coords, r), residueDisplacement(a, b)geometry helpers

Residue and atom indices are 0-based; selections, colours and annotations use residue indices.

                 'description': 'Residue pairs > 3 apart with heavy atoms within 4 Å.'}],
}

    return {'contacts': 12}
  • compute runs for every conformation when an ensemble is opened (also for .rcv conversion); return numbers or None. Exceptions are reported as a warning and never stop loading.
  • The values become metrics plugin.<id>.<key> everywhere (energy panel, tables, plots, CSV, .rcv files). RCV remembers which plugins were active, so a prediction folder is re-evaluated when the plugin set changes.
  • numpy and scipy are available; installer builds contain only the packages RCV itself needs.
  • Example: examples/viewer_plugins/tertiary_contacts.py.

5. Testing, sharing, good practice

  • Debugging: enable developer mode, open the developer tools (F12) and use console.log; load errors are listed in Plugins ▸ Manage plugins. For Python plugins, errors appear as warnings when the ensemble opens.
  • Automated tests: keep computations in plain functions (no DOM) and test them with Node.js, as RCV does in tests/js/ (load an ensemble document exported with rcv export-document).
  • Sharing: a plugin is a single file — share it, or publish it with a licence header. RCV is GPL-3.0; plugins are your own work and may use any licence.
  • Style: use api.palette.colors and <svg class="chart"> so figures match the rest of RCV; label units; never block the window for more than a moment (use setTimeout / await to split long loops).
  • Safety: plugins run with your user rights, like any program. Install only plugins you trust.
